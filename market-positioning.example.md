# Market Positioning — living reference (sanitized example)

Purpose: make tailoring reflect where demand is MOVING, not just the JD text. This file is the skill's forward-looking evidence base. It is rewritten, not appended forever: the "Current posture" section always reflects the latest evidence; older reads move to the changelog.

**Read this file** at the start of every tailoring and discovery run (after the dossier and baseline resume).
**Update this file** at the end of every discovery run: revise "Current posture" if the new report changes the picture, add one changelog line citing the report.

## Current posture (updated YYYY-MM-DD; evidence: discovery/YYYY-MM-DD-report-a.md, discovery/YYYY-MM-DD-report-b.md)

### Where demand is moving (lanes, in priority order)

1. **[Lane 1 — e.g., applied-AI architect / enablement roles at AI platform companies.]** What the latest sweep showed; which requirements map line-by-line to the candidate's evidence; what to lead with (and what NOT to lead with).
2. **[Lane 2 — e.g., AI-delivery roles at enterprise software companies.]** Why this lane credits the candidate's actual years where titled-track lanes do not.
3. **[Lane 3 — e.g., domain-architect roles naming the candidate's deepest verified suit as a requirement.]** Conversion rationale + the honest narrow framing of any known gap, with the evidence line that counters the broad version of the objection.
4. **[Lane 4 — conditional lane.]** Near-perfect JD matches gated by a practical constraint; the condition that must be confirmed before investing effort.

### Hard gates the market is enforcing (auto-screen before tailoring)

- **Titled-years minimums are literal.** Do not spend packages against titled-track minimums the dossier cannot meet; adjacent lanes credit the same evidence without the title gate.
- **PERM-pattern postings** (hyper-specific enumerated minimums + a salary band only ~$1–3K wide + "foreign equivalent" phrasing): auto-skip; drafted around an incumbent.
- **People-manager scope** without a people-management record: skip.
- **[Jurisdiction-specific practical gates]** — e.g., verification-program enrollment a future work-authorization step depends on; confirm before relying on small sponsors.

### Tactical rules evidenced by recent runs

- **Stagger applications into the same org** (submit strongest 1–2, hold siblings ~2 weeks); a focused pair beats a shotgun spread.
- **Dedupe against existing packages before building** — a second application to the same req harms more than helps.
- **Respect employer AI-usage policies:** where stated, the first draft is the candidate's.
- **Capture applicant counts and posted/reposted dates** when visible; fresh + low-count postings get packaging priority.

### What this means for tailoring emphasis (until superseded)

- Position as: **[one-sentence positioning that the current evidence supports]**. The differentiators the market is paying for right now: [3–4 evidence-backed differentiators]. [Name the frames that under-price or gate out the candidate.]

## Update protocol (for the skill)

After writing any discovery report:
1. Re-read "Current posture". If the new evidence confirms it, add only a changelog line.
2. If it changes the picture (new lane, new hard gate, a lane going cold), rewrite the affected bullets and update the date stamp. Keep "Current posture" under ~60 lines; this file must stay readable in one pass.
3. Never delete the changelog.
